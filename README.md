# 🐼 Panda

A cute floating desktop panda that keeps your daily tasks on track.

**[🌐 Website](https://rakshita25bcs10338-collab.github.io/Panda/)** · **[⬇️ Download for Mac](https://github.com/rakshita25bcs10338-collab/Panda/releases/latest/download/Panda.zip)**

## What it does

- A soft, chibi panda lives on your screen. Drag it anywhere and it remembers its spot.
- Click the panda to open a cozy cream task panel right next to it.
- Choose how many task slots you want (1 to 8) and set a daily check-in time.
- After the check-in time, if tasks are unfinished, the panda wakes up and follows your cursor.
- Finish everything and the panda puts on a party hat. 🎉
- The window is transparent, always on top, and click-through everywhere except the panda and the panel.

## Install (Mac, Apple Silicon)

1. Download `Panda.zip` from the [latest release](https://github.com/rakshita25bcs10338-collab/Panda/releases/latest).
2. Unzip it and drag **Panda** into your **Applications** folder.
3. Right-click Panda, choose **Open**, then click **Open** again. (macOS asks because the app isn't signed.)

To quit, click the panda, then ⚙, then **Quit Panda**.

## Run from source

You need [Node.js](https://nodejs.org) 18 or newer.

```bash
npm install
npm start
```

To build the app yourself:

```bash
npm run package
```

## Built with

Electron Forge, Vite, TypeScript, React and electron-store.
